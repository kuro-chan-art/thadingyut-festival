# Thadingyut Festival | NEXTogether

## Run the website
1. Extract the ZIP file.
2. Open the `Thadingyut_Music_Updated` folder in VS Code.
3. Run `index.html` with VS Code Live Server, or open it in a browser.

## Background music
- The website tries to start the background music automatically when the page opens.
- Music loops continuously.
- Use the **Volume** slider to adjust the sound from 0% to 100%.
- Use **Play music / Pause music** to control playback.
- If the browser blocks autoplay with sound, click **Play music** once. The website also retries when you first interact with the page.

**Important:** Chrome and other browsers may block autoplay with sound depending on their settings and prior interaction. A website cannot reliably override that browser restriction.

## Included features
- Burmese and English animated Thadingyut greetings
- Animated lava lamp with glow intensity, animation speed, and liquid color controls
- Pause/resume animation, replay greeting, and reset settings
- Responsive layout for desktop and mobile
- Background music with looping, volume control, and play/pause
